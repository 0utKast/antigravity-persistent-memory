Antigravity Persistent Memory (L0–L3)

Sistema Local-First de memoria persistente en cuatro capas para convertir a tus agentes de IA en auténticos especialistas mediante experiencia real verificada: diarios en Markdown bajo Git, índice SQLite FTS5 + BM25, servidor MCP federado, compuerta anti-envenenamiento (PROVISIONAL → VERIFIED) y guardianes automáticos de presupuesto (24.000 bytes y 20.000 tokens Always-On).

Instalación en 1 Comando (Windows / macOS / Linux)

Clona el repositorio e instala automáticamente el plugin, las reglas globales, el servidor MCP persistent_memory y los hooks SessionStart + Stop sin sobrescribir tus servidores existentes:

git clone https://github.com/0utKast/antigravity-persistent-memory.git
cd antigravity-persistent-memory
python install_persistent_memory.py

Para auditar tu estación o probar el ciclo completo de 6 etapas en sandbox sin tocar ~/.gemini:

python install_persistent_memory.py --check
python laboratorio_memoria_persistente_antigravity.py
python tests/test_persistent_memory_portable.py
